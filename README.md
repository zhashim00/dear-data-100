# dear-data-100

Dear Data 100: a record of my training days.

One row per day, including rest days.

## Columns

| Column       | Meaning                                                          |
|--------------|------------------------------------------------------------------|
| date         | yyyy-mm-dd                                                       |
| day_type     | arms, chest_back, legs or rest  |
| activity     | what I actually did  |
| duration_min | length of the session in whole minutes         
| effort       | 1 to 10, where        

## Data source

I use an app called hevy to track all my workouts and strava to track my running and basketball
