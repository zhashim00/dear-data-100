# dear-data-100

Dear Data 100: a record of the drinks I have each day.

One row per drink.

| Column | Meaning |
|---|---|
| date | dd/mm/yyyy |
| time | 24 hour, hh:mm |
| drink | water, tea, coffee, etc. |
| temp | hot or cold |
| why | thirsty, habit, tired, bored, social |
| mood | 1 to 5, how I feel as I drink it |
